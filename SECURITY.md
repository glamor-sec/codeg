# Security Policy

## Supported Versions
This project provides security patches for the following releases. Please upgrade to a supported version to receive security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :x:                |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability
**Do NOT open public GitHub issues to report security vulnerabilities.**
Public disclosure of unfixed vulnerabilities puts all users at risk.

Please contact maintainers via private email to submit vulnerability reports.
A complete report should include affected versions, source/sink analysis, exploit chain and PoC.

We aim to acknowledge vulnerability submissions within 5 business days, and provide regular investigation updates.
This project follows coordinated vulnerability disclosure. Reporters will receive credit in security advisories unless anonymity is requested.
